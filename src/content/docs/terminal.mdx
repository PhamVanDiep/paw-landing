Terminal trong PAW là phiên `claude` thật. Mọi thứ bạn làm được với Claude Code ngoài terminal đều làm được ở đây.

## Sao chép và dán

| Thao tác | Windows, Ubuntu | macOS |
| --- | --- | --- |
| Dán | Ctrl+V hoặc Ctrl+Shift+V | ⌘V |
| Sao chép | Ctrl+C khi đang bôi đen, hoặc Ctrl+Shift+C | ⌘C |
| Ngắt Claude | Ctrl+C khi không bôi đen | Ctrl+C |

Chuột phải mở menu **Sao chép**, **Dán**, **Chọn tất cả**. Phiên đã kết thúc thì chỉ sao chép được.

## Gửi ảnh và file

- Dán ảnh chụp màn hình vào terminal: PAW lưu ảnh rồi dán đường dẫn để Claude đọc. App nhận PNG, JPEG, GIF và WebP, tối đa 20 MB.
- Kéo file từ Explorer hoặc Finder vào terminal: PAW dán đường dẫn file.
