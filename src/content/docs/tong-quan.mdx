PMIS Auto Work (PAW) là ứng dụng desktop cho Windows, macOS và Ubuntu. App hiện việc Azure DevOps được giao cho bạn trên bảng Kanban, rồi chạy Claude Code cho từng việc ngay trong thư mục project trên máy bạn.

## PAW làm gì

- Đồng bộ work item được gán cho bạn từ Azure DevOps Server về một board.
- Mở một phiên `claude` tương tác cho mỗi việc, hiển thị trong terminal của app.
- Theo dõi phiên nào đang chạy, phiên nào đang chờ bạn, và báo cho bạn biết.
- Cập nhật trạng thái work item trên Azure DevOps khi bạn kéo thẻ.

## PAW không làm gì

- Không tự duyệt thay bạn. Claude xin phép thế nào thì bạn trả lời ngay trong terminal như vậy.
- Không clone repo và không chuẩn bị nhánh giúp bạn. Claude làm trên bản làm việc bạn đã có.
- Không gửi dữ liệu đến máy chủ riêng nào của PAW. App chỉ nói chuyện với Azure DevOps, Claude Code trên máy bạn, và Telegram nếu bạn bật.
