## Cần có

- Máy Windows x64, macOS (Apple Silicon hoặc Intel), hoặc Ubuntu x64.
- [Claude Code](/docs/claude-code) đã cài và đã đăng nhập.
- `git` và quyền truy cập repo của project, bằng SSH key hoặc credential helper trên máy.
- Mạng tới Azure DevOps Server `https://devops.evn.com.vn`.
- Một [PAT Azure DevOps](/docs/lay-pat) có quyền Work Items.
- Repo của project đã được clone sẵn về máy.

## Không bắt buộc

- [Plugin pmis3-skills](/docs/plugin), nếu team bạn dùng quy trình PMIS3. Không có plugin thì PAW vẫn chạy, bạn tự tải lên [luật trạng thái](/docs/luat-trang-thai).
- Bot [Telegram](/docs/telegram), nếu muốn nhận thông báo trên điện thoại.
